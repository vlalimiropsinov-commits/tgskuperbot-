# Бот автоприёма заявок в Telegram-канал

Ловит заявки на вступление и одобряет их автоматически. Опционально: задержка,
приветствие в личку, уведомления тебе, статистика.

## 1. Создать бота

1. Пишешь @BotFather → `/newbot` → получаешь токен вида `8123456789:AAH...`.
2. Открываешь `.env.example`, переименовываешь в `.env`, вставляешь токен в `BOT_TOKEN`.

## 2. Настроить канал (без этого заявки не появятся)

1. Канал должен быть **приватным**, в настройках приглашений включи
   **«Заявки на вступление»** (Approve new members / Request to join).
   Люди должны заходить по ссылке-приглашению с галкой «заявка», а не по обычной.
2. Добавь бота в канал **администратором**.
3. Дай ему право **«Добавлять подписчиков»** (Add members / Invite users) —
   именно оно позволяет одобрять заявки. Остальные права не нужны.

## 3. Настройки в .env

| Переменная      | Что делает |
|-----------------|-----------|
| `BOT_TOKEN`     | токен от BotFather (обязательно) |
| `ALLOWED_CHATS` | ID каналов через запятую. Пусто = принимать везде, где бот админ |
| `ADMINS`        | твой Telegram ID, кому доступна `/stats` |
| `DELAY_MIN` / `DELAY_MAX` | задержка перед одобрением в секундах. `0/0` = мгновенно. `5/40` = случайно 5–40 сек |
| `SEND_WELCOME`  | `true` — писать новому подписчику в личку |
| `WELCOME_TEXT`  | текст приветствия, поддерживает `{name}`, `{full_name}`, `{username}`, `{chat}`, `{id}` |
| `LOG_CHAT_ID`   | твой ID — будешь получать уведомление о каждом принятом |

Свой ID и ID канала узнать просто: напиши боту `/id`, а для канала — перешли
боту в личку любой пост из канала и снова отправь `/id`.

> Приветствие в личку дойдёт, только если человек когда-то нажимал `/start` у
> бота. Это ограничение Telegram, не баг. Если не дошло — в логе будет строка
> «Личку … написать нельзя», бот продолжит работать.

## 4. Запуск на VPS (рекомендуется)

С домашнего интернета `api.telegram.org` не открывается, поэтому крутим на сервере.

Заливаем архив (выполнять в PowerShell на компе):

```
scp C:\Users\ibragim\Downloads\tg-approve-bot.zip root@138.16.226.176:/root/
```

Дальше по одной команде на сервере:

```
ssh root@138.16.226.176
```
```
apt update && apt install -y python3-venv unzip
```
```
cd /root && unzip -o tg-approve-bot.zip -d /root/ && cd /root/tg-approve-bot
```
```
python3 -m venv venv && venv/bin/pip install -U pip && venv/bin/pip install -r requirements.txt
```
```
cp .env.example .env
```
```
nano .env
```
(вставляешь токен, `Ctrl+O`, `Enter`, `Ctrl+X`)

Пробный запуск, чтобы увидеть ошибки сразу:
```
venv/bin/python bot.py
```
Должна появиться строка «Запущен как @твой_бот». Останавливаешь `Ctrl+C`.

Ставим в автозапуск:
```
cp /root/tg-approve-bot/approvebot.service /etc/systemd/system/approvebot.service
```
```
systemctl daemon-reload && systemctl enable --now approvebot
```
```
systemctl status approvebot --no-pager
```

Смотреть логи:
```
tail -n 50 -f /var/log/approvebot.log
```

Перезапуск после правок:
```
systemctl restart approvebot
```

## 5. Запуск на Windows

Нужен VPN/прокси, иначе будет `WinError 121`. Если VPN есть — просто двойной
клик по `start.bat` (сам создаст venv и поставит зависимости).

## Частые ошибки

| Что видно | Причина |
|-----------|---------|
| Бот запустился, но заявки не приходят | в канале не включены «Заявки на вступление», либо люди идут по обычной ссылке |
| `Not enough rights` / `CHAT_ADMIN_REQUIRED` | нет права «Добавлять подписчиков» |
| `HIDE_REQUESTER_MISSING` | заявку уже одобрили/отклонили вручную |
| `Unauthorized` | неверный токен в `.env` |
| `WinError 121` при локальном запуске | провайдер режет api.telegram.org — нужен VPS или VPN |
